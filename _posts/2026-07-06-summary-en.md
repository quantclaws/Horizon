## [Free 2021 Guide to Compiler Construction and Language Design Released Online](https://dthain.github.io/books/compiler/) ⭐️ 8.0/10

In 2021, Doug Thain published a freely available online book titled 'Introduction to Compilers and Language Design', offering comprehensive coverage of compiler construction with practical exercises. The resource serves as an accessible educational tool for students and practitioners seeking to learn compiler techniques, filling a gap for high-quality, freely accessible tutorials. The book includes chapters on lexical analysis, parsing, semantic analysis, optimization (including constant folding and tree rewriting), code generation, and ends with a capstone project building a C‑style compiler.

**Background**: A compiler translates high‑level source code into low‑level machine code or assembly, enabling programs to run on hardware. Language design involves defining the syntax, semantics, and features of programming languages to make them expressive and usable. This tutorial assumes basic programming knowledge but no prior compiler experience, introducing both topics in a structured way.
