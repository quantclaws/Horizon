## [Fireworks AI launches Ember-1, a Kimi K3‑based model using 40% fewer tokens](https://fireworks.ai/blog/ember-1) ⭐️ 8.0/10

Fireworks AI announced Ember-1, a specialized model built on Kimi K3 that delivers the same quality while using roughly 40% fewer tokens, and released it as a research preview on its serverless platform. Ember-1 demonstrates how post‑training can improve inference efficiency, lowering costs for developers and advancing the trend toward smaller, faster open‑source models. The model was created by post‑training Kimi K3 to shorten reasoning traces, resulting in about 40% fewer tokens per output; Fireworks lists pricing at $3 per million input tokens and $15 per million output tokens (or $4.4/M output in some notes) and offers two‑week serverless access for community feedback.

hackernews · gmays · Sep 27, 17:31 · [Discussion](https://news.ycombinator.com/item?id=49868830)

**Background**: Kimi K3 is a large language model known for strong reasoning abilities but relatively high token usage. Fireworks AI is a platform that provides model serving, training, and inference services, often hosting open‑source models. Post‑training techniques such as reinforcement learning or fine‑tuning can modify a model’s behavior without changing its core weights, enabling traits like shorter reasoning traces. By reducing token consumption, models like Ember-1 lower latency and cost, making AI more accessible for applications that require frequent calls.

## [Google Search Turns Weird with AI Summaries](https://sancho.bearblog.dev/google-weird/) ⭐️ 8.0/10

A blog post examines how Google's search results now display AI-generated summaries at the top, causing user confusion as illustrated by a query about the Halifax Wanderers. This shift reflects a broader trend toward conversational answer engines, potentially altering how users seek information and raising concerns about accuracy and trust. The AI summary incorrectly claimed Halifax Wanderers had secured a playoff spot, while the user knew they were still fifth, highlighting the risk of hallucinated answers.

hackernews · sancho-panza · Sep 27, 20:12 · [Discussion](https://news.ycombinator.com/item?id=49870367)

**Discussion**: Commenters are divided: some praise the AI summaries as a quality‑of‑life improvement for average users, while others find them disturbing or manipulative, linking the change to loneliness and monetization; one user shared a link to an AI‑free search alternative.
